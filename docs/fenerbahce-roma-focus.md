# Fenerbahçe–Roma match focus

The permanent pages are `/fenerbahce-roma-maci` and `/en/fenerbahce-vs-roma`.
`data/fenerbahce-roma-focus.json` holds the sourced editorial preview and probable XIs. These are never labelled official. An API-Football XI replaces a side only when it contains eleven distinct players; an empty follow-up response does not remove an already confirmed XI.

`match-focus.js` is the shared browser/static renderer. The homepage consumes its existing score stream through `futbolradar:score-snapshot`. The permanent page uses the existing `/api/live-score-stream`. Both refresh `/api/match-detail?fixtureId=1635659&id=fenerbahce-roma-2026-09-10`; no credentials are shipped to the browser. Refresh cadence is five minutes before the lineup window, one minute inside it, fifteen seconds around kick-off/during play, and five minutes after full time. The provider's existing single-flight cache and quota controls remain in force. Background tabs stop timers and streams. Failures back off; live data older than ninety seconds is clearly marked delayed.

The scheduled kickoff ends the countdown but does not invent a live status, score or minute. Provider confirmation activates LIVE. Added time, half time, interruption/postponement and full time have distinct states. Scores may decrease after a VAR correction. Older packets and non-final responses after confirmed full time cannot roll the board backwards.

Both the normal build and scheduled update use `scripts/lib/postprocessChain.mjs`. The page generator runs after the English homepage generator and before shared layout; the focus ticker runs after shared layout. The generator reads the current fixture, curated records and historical match archive, so confirmed results remain in static HTML on subsequent builds. Existing scheduled result/archive synchronization supplies those records. The client switches the title, description and report as soon as it receives full time. The promotional homepage window closes on 11 September 2026 at 23:59:59 Istanbul time; the permanent pages remain.

Validation: `node scripts/test-match-focus.mjs`, `node scripts/test-match-lineup-api.mjs`, `node scripts/test-live-score-stream.mjs`, `node scripts/test-postprocess-chain.mjs`, `node scripts/test-source-links.mjs`, `node scripts/qa.mjs`, TypeScript and `node scripts/audit-interaction-routes.mjs`. Browser checks cover the actual homepage card, lineup and broadcast anchors, language switch, 390px layout and separate local simulated live/final scenarios. Simulated data is never included in production assets.
